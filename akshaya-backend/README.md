# Akshaya Advisory Backend

## Purpose
This FastAPI backend serves as the core intelligence engine for the Akshaya Advisory chatbot. It coordinates RAG (Retrieval-Augmented Generation) interactions between the user, our local FAISS vector store, and the Gemini LLM.

## MVP Services
The application strictly supports these three English-only MVP services:
1. **Aadhaar Services**
2. **Kerala Ration Card Services**
3. **Scholarship Services** (National Scholarship Portal)

## Implemented API Endpoints
- **Health Check (`/health`)**: Verifies backend availability.
- **Chat (`/chat`)**: Receives user queries, orchestrates FAISS retrieval and LLM generation.
- **Feedback (`/feedback`)**: Captures user ratings and feedback for model improvement.
- **History (`/history`)**: Retrieves previous conversation context.
- **Services (`/services`)**: Manages metadata for supported MVP categories.

## Architecture & Storage
- **SQLite Database**: Manages state for conversations, individual messages, reference citations, user feedback, and security audit logs. 
  *(Note: The live runtime `akshaya.db` is strictly excluded from version control to protect user data.)*
- **FAISS Vector Store**: Handles high-performance semantic similarity retrieval. It stores embeddings of document chunks to quickly retrieve the most relevant official guidance matching user queries.

## Data Pipeline Structure
- **Raw Documents (`data/raw_documents/`)**: Holds the curated, official public PDFs and HTML source files. *Only official, public government documents are permitted.*
- **Processed Data (`data/processed/`)**: Contains cleaned text, tokenized chunks, and metadata generated by the ingestion pipeline.
- **Vector Store (`data/vector_store/`)**: The actual FAISS `.index` files containing mathematical embeddings used for retrieval. 

*Note: Processed text and generated vector indexes are ignored by Git. They should be regenerated locally using the ingestion scripts.*

## Setup Instructions

1. **Virtual Environment Setup:**
   ```bash
   cd akshaya-backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Environment Variables:**
   Copy the example environment file and fill in your Gemini API key:
   ```bash
   copy .env.example .env
   ```
   *Warning: Never commit your `.env` file to version control.*

3. **Running the Application:**
   Start the FastAPI server:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

## Document Ingestion Instructions
To rebuild the local RAG knowledge base from raw documents:
1. Ensure your `.env` is configured.
2. Run the ingestion pipeline in sequence:
   ```bash
   python -m ingestion.extract_text
   python -m ingestion.chunk_documents
   python -m ingestion.generate_embeddings
   python -m ingestion.build_faiss_index
   ```

## Anti-Hallucination & Grounding Safeguards
- **Intent Classification**: Queries are filtered to ensure they match one of the three supported MVP services.
- **Privacy Filtering**: PII is scrubbed before being passed to external LLMs.
- **Confidence Scoring**: Responses are graded; low-confidence RAG matches automatically trigger a fallback warning advising the user to contact a local Akshaya center.
- **Citation Validation**: The LLM is strictly instructed to only answer using provided context from the FAISS retrieval, rejecting out-of-bounds questions.
